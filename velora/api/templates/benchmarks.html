What this does not measure

  • Coverage is {{ "%.0f%%"|format(latest.detection_coverage * 100) }} — a detection outside the suite's ground truth is counted as neither a true nor a false positive, so it neither flatters nor penalises these figures.
  • Evidence completeness is {{ "%.0f%%"|format(latest.evidence_completeness * 100) }}: the share of expected detections that also produced every required piece of evidence.
  • These numbers describe this suite against this lab application. They are not a detection rate for arbitrary web applications, and Velora does not extrapolate one.
  • A case Velora has no check for cannot be scored here at all; it is a gap in coverage, not a measured success.
